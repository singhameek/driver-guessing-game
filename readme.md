This is a game where you guess an F1 driver based on their driver number. The script picks randomly from a list of drivers, mixes it with 3 random false answers, and presents it as multiple choice. In build 1, it is very simple, as there is no loop, and you must refresh to load another round. Soon, in following builds, I will add:

- leaderboard
- loop to make it work endlessly
- center buttons
- more features, such as different game modes
